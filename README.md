# GameLingo-Updates

مستودع التحديثات المستقل لتطبيق GameLingo-Mobile. سورس الكود في مستودع منفصل (`GameLingo-Mobile`)، وهنا يعيش كل ما يخص الإصدارات المنشورة:

- `latest.json` — آخر إصدار متاح: رقم الإصدار، رقم البناء، أقل بناء مدعوم، التغييرات، رابط التنزيل، SHA-256، وعلم التحديث الإجباري.
- `CHANGELOG.md` — سجل التغييرات الكامل بالعربي.
- ملفات APK الموقعة تُنشر كـ GitHub Releases في هذا المستودع عبر workflow النشر في مستودع السورس.

التطبيق يقرأ `latest.json` مباشرة من هنا عند فتحه، يقارن الإصدار، وينزل التحديث بعد التحقق من SHA-256 واسم الحزمة والتوقيع. لا يعتمد على مستودع السورس في شيء.
